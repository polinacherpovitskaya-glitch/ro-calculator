# Прозрачный расчёт почасовой зарплаты

## Контекст

В payroll-сводке сумма сотрудника с почасовой ставкой выглядит завышенной, если часть часов пришлась на выходные. Например, для 80 часов при обычной ставке 500 ₽ и ставке выходного 750 ₽ результат может быть на 1 825 ₽ выше простого `80 × 500`.

Текущий расчёт математически корректен: 7,3 часа выходного дают надбавку `7,3 × (750 − 500) = 1 825 ₽`. Проблема в представлении:

- будние часы почасового сотрудника одновременно выводятся как «Будни» и «Сверх»;
- видны часы и итог, но не ставки и денежные компоненты;
- колонка «К выплате» не объясняет, что для окладного сотрудника здесь показаны только доплаты по табелю.

## Цель

Сделать итог payroll проверяемым прямо в таблице: оператор должен видеть, какие часы оплачены по обычной, выходной и праздничной ставкам и откуда появилась надбавка.

## Требования

- Для профиля `hourly` будние часы считаются почасовыми, а не называются сверхурочными.
- `overtimeHours` означает только часы сверх порога оклада; у чисто почасового профиля это значение равно нулю.
- Payroll-строка содержит отдельные денежные компоненты для будней, сверхурочных, выходных и праздников.
- В таблице показывается компактная формула со ставками и суммами.
- Для почасового сотрудника отдельно показывается положительная надбавка выходных/праздников относительно обычной ставки.
- Текущие ставки и итоговая сумма не меняются.
- Для окладных сотрудников месячный оклад по-прежнему не прибавляется в эту сводку: здесь остаются только доплаты по табелю.

## Проверочный пример

При 72,7 буднего часа по 500 ₽ и 7,3 часа выходного по 750 ₽:

- всего часов: 80;
- будни: 36 350 ₽;
- выходные: 5 475 ₽;
- итого по табелю: 41 825 ₽;
- надбавка к расчёту `80 × 500`: 1 825 ₽.

## Вне scope

- изменение ставок сотрудников;
- изменение календарного определения выходных и праздников;
- добавление премий, удержаний или налогового расчёта;
- изменение Telegram-процесса сдачи часов.

## Приёмка

- Проверочный пример выше воспроизводится автоматическим тестом.
- В строке почасового сотрудника нет дублирования будних часов в поле сверхурочных.
- Формула в UI объясняет надбавку 1 825 ₽.
- Semimonth-правила окладных сотрудников продолжают проходить существующий smoke-тест.
