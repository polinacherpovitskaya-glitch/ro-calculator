# Автоматическое объединение существующих B2C-составов

## Контекст

Режим составного пластикового изделия появился в v450. У существующих наборов
поле `composite_plastic_item` отсутствует, хотя несколько строк
`plastic_items` уже описывают детали одного продаваемого товара. В частности,
карточка «Кликер \"Звезда\"» была дополнена второй деталью из вкладки v449 и
поэтому не могла сохранить новый флаг.

## Решение

- Если `composite_plastic_item` явно сохранён, использовать его значение.
- Если поле отсутствует и у набора больше одной действующей пластиковой строки,
  считать набор составным.
- Если пластиковая строка одна, сохранять прежнее поведение.
- Пользователь может открыть карточку в новой версии, снять переключатель и
  сохранить явное `false`, если отдельные производственные строки действительно
  нужны.

Такой fallback исправляет старые многокомпонентные наборы без миграции базы и не
лишает пользователя ручного управления режимом.

## Критерии готовности

- legacy-набор с двумя молдами нормализуется как составной;
- явно сохранённый `false` не переопределяется;
- набор с одним молдом остаётся обычным;
- regression-тесты B2C и version smoke проходят.
