# Составной бланк из нескольких молдов

## Проблема

Поле `Кол-во молдов в изделии` увеличивает только закупочную стоимость формы.
Оно не описывает отдельные проливки и поэтому не может правильно посчитать
готовое изделие вроде брелока-кликера: основа производится со скоростью
60 шт/ч, звёздочка — 45 шт/ч, а готовый кликер требует обе детали.

## Цель

В карточке бланка можно выбрать несколько существующих бланков-компонентов и
указать, сколько экземпляров каждой детали входит в одно готовое изделие.
Карточка и калькулятор должны использовать суммарные параметры готового изделия.

Для компонентов `60 шт/ч + 45 шт/ч` расчётная производительность равна:

`1 / (1 / 60 + 1 / 45) = 25,71 готовых изделий/ч`.

## Поведение

- Режим `Составное изделие` включается явно в форме бланка.
- В состав можно добавить минимум два существующих бланка; текущий бланк нельзя
  добавить сам в себя, дубликаты объединяются количеством.
- Для каждого компонента сохраняются `mold_id` и `qty` в `mold_data` без новой
  колонки базы.
- Производительность считается через сумму времени всех последовательных
  проливок: `1 / Σ(qty / pph)`.
- Вес готового изделия равен `Σ(qty × weight)`.
- Стоимость комплекта молдов равна сумме полной стоимости компонентов с учётом
  их количества, курса и доставки; амортизация по-прежнему делится на 4500.
- В таблице бланков показывается состав и расчётная производительность.
- При выборе составного бланка в калькуляторе передаются итоговые скорость, вес
  и стоимость комплекта молдов.
- Обычные бланки и старые записи с `mold_count > 1`, но без списка компонентов,
  продолжают считаться по прежней формуле.

## Границы

- Компоненты считаются последовательными проливками на одном производственном
  ресурсе; параллельные линии в этой задаче не моделируются.
- Размеры, фото, встроенная фурнитура и сборка остаются параметрами готового
  изделия и не складываются автоматически.
- Нельзя создавать циклические составы: компонентом может быть только обычный
  бланк, а не другой составной бланк.

## Критерии приёмки

- Кликер с основой `60 шт/ч` и звёздочкой `45 шт/ч` показывает `25,71 шт/ч`.
- Вес и полная стоимость двух форм суммируются.
- Цена в бланках и себестоимость в калькуляторе используют эти итоговые данные.
- Состав сохраняется, загружается и редактируется без потери данных.
- Старые карточки без состава не меняют результат.
