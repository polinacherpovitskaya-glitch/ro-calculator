# Быстрое открытие формы приёмки склада

**Дата:** 2026-09-08  
**Статус:** implementation ready  
**Область:** форма новой складской приёмки

## Проблема

После загрузки склада форма новой приёмки всё равно ждала повторное чтение
заказов для опциональных полей клиентского молда. При медленном ответе базы
основной выбор складской позиции несколько секунд оставался пустым. Production
smoke дважды зафиксировал открытую форму без picker, хотя складской кэш уже был
загружен.

## Цели

- Сразу показывать выбор складской позиции из уже загруженного кэша.
- Не блокировать обычную строку приёмки загрузкой заказов для молдов.
- Сохранить загрузку заказов в фоне для последующего выбора клиентского молда.

## Решение

В `renderShipmentItemsTable` загружать заказы синхронно только тогда, когда в
форме уже есть новая позиция категории «молд». Для обычной складской позиции
запускать эту необязательную загрузку в фоне и сразу строить таблицу.

## Проверка

- `node tests/warehouse-migration-smoke.js`
- `node tests/version-smoke.js`
- production `Live site smoke`

## Вне области

- Изменение схемы складских позиций или приёмок.
- Изменение production smoke-селекторов.
- Изменение загрузки B2C-наборов.
