## M1. Подтверждённое сохранение `[ ]`

- [ ] Повторять идемпотентный `upsert` набора после временного сбоя.
- [ ] Не выдавать локальную запись за успешную синхронизацию с общей базой.
- [ ] Сохранять прежнее поведение в локальном режиме разработки.
